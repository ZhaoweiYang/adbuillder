# Facebook 广告 Excel 导入生成器

一个**纯前端、零依赖**的网页工具。填写广告信息后，一键生成符合 **Facebook Ads Manager 批量导入（Bulk Import / 批量上传）** 格式的 `.xlsx` 文件，导入广告管理工具即可快速批量创建广告。

## 功能

- 表单式填写：广告系列（Campaign）→ 广告组（Ad Set）→ 多个广告（Ad）
- 支持一次添加多个广告（同一系列/广告组下）
- 一键导出标准 `.xlsx`（列头与 Facebook 批量导入模板一致）
- 纯前端运行，无需后端、无需联网、不上传任何数据（隐私安全）
- 自带轻量 XLSX 生成器（不依赖任何第三方库 / CDN）

## 使用

直接用浏览器打开 `index.html` 即可，无需安装。

或本地起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 如何导入 Facebook

1. 在本工具中填写信息并点击「生成 Excel 文件」下载 `.xlsx`。
2. 打开 [Facebook Ads Manager（广告管理工具）](https://www.facebook.com/adsmanager)。
3. 选择左上角的「**广告**」→「**导入广告**」/「批量上传」（Bulk import）。
4. 上传生成的 `.xlsx` 文件，按提示检查映射并发布。

> 注意：Facebook 的批量导入列名/规则会不定期调整，且部分字段（如图片需用 Image Hash、像素 ID、受众等）依赖你账户内已有的资源。导入后请在界面中核对并补全后再发布。导入不会立刻花费预算，发布前可随时修改。

## 字段说明

文件包含 Facebook 批量导入常用列，按「广告系列 / 广告组 / 广告」三层组织，每个广告占一行，系列与广告组信息在同组的行中重复填写。
