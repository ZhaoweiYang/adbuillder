📌 如何导入 Facebook

  1. 点击「生成 Excel 文件」下载 .xlsx。
  2. 打开 Ads Manager 广告管理工具。
  3. 在「广告」标签页选择「导入广告 / 批量上传 (Bulk import)」并上传文件。
  4. 核对字段映射（图片需用账户内的 Image Hash、像素 ID 等），确认后发布。

提示：导入不会立即扣费，发布前可随时修改。Facebook 的列名与规则会不定期更新， 预算字段以账户货币的最小单位（如美分）填写。本工具所有数据均在本地浏览器处理，不会上传。
